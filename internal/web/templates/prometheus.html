Connecting Prometheus

Prometheus learns the device list and each device's interval through HTTP Service Discovery. After you add a device here, nothing needs to change in Prometheus. Prometheus never talks to the devices: it reads the latest values from the exporter's memory.

prometheus.yml

{{if .HTTPS}}
scrape_configs:
  - job_name: zirox-snmp
    tls_config:
      ca_file: /etc/prometheus/zirox.crt
    http_sd_configs:
      - url: {{.Base}}/sd
        refresh_interval: 60s
        tls_config:
          ca_file: /etc/prometheus/zirox.crt

Zirox serves HTTPS{{if .SelfSigned}} with a self-signed certificate it made itself{{end}}; the service discovery tells Prometheus to scrape the targets over HTTPS too. {{if .SelfSigned}}Save the certificate as /etc/prometheus/zirox.crt (in a container: next to prometheus.yml, mounted into it) so Prometheus can check it{{else}}If your certificate is signed by an internal CA that the Prometheus server does not trust, put that CA's certificate in ca_file; with a public CA leave tls_config out{{end}}. The address in the URL must be one the certificate names{{if .SelfSigned}} (the host name and the server's addresses; more with ZIROX_TLS_HOSTS){{end}}.

Certificate SHA-256: {{.Fingerprint}}, valid until {{.NotAfter.Format "2006-01-02"}}. Compare it with what your browser shows before you accept the certificate the first time. Quick and less safe instead of ca_file: insecure_skip_verify: true.

{{else}}
scrape_configs:
  - job_name: zirox-snmp
    http_sd_configs:
      - url: {{.Base}}/sd
        refresh_interval: 60s

Zirox speaks plain HTTP. To turn on HTTPS, run the installer with --https (self-signed certificate) or --tls-cert FILE --tls-key FILE.

{{end}}

If ZIROX_SCRAPE_TOKEN is set, add authorization: {credentials: "<token>"} both to http_sd_configs and to the job itself.

Each device becomes its own target with the labels instance, device, group, address, sysName. The scrape interval (__scrape_interval__) equals the device's poll interval.

Alternative: one target with all devices

  - job_name: zirox-snmp-all
    scrape_interval: 60s
    metrics_path: /metrics/all
    static_configs:
      - targets: ['{{.Host}}']

Endpoints

/sdtarget list for HTTP SD (JSON)
/probe?target=<id|name|IP>metrics of one device
/metrics/allall devices in one response, with device and group labels
/metricshealth of the exporter itself

Example Grafana queries

rate(ifHCInOctets{device="core-nx-01"}[5m]) * 8          # inbound traffic, bit/s
rate(ifInErrors[5m]) > 0                                   # ports with errors
zirox_cpu_utilization_percent{window="1m"}                 # CPU load
zirox_temperature_celsius                                  # temperature
zirox_poll_success == 0                                    # devices that do not answer
